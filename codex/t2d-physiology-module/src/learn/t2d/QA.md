# QA Checklist - T2D Physiology Module

## Navigation
- Open `/learn/t2d` and verify sticky TOC is visible.
- Click each pill tab and confirm smooth fast glide to the matching section.
- Scroll manually and confirm active tab updates (scroll spy).

## Theme + Visual
- Confirm light optimistic background and soft gradient are present.
- Verify cards use rounded corners, soft shadows, and subtle glass effect.
- Check section tint backgrounds:
  - Normal (mint)
  - Resistance (sky)
  - Beta (indigo)
  - Complications (coral)

## Parallax
- Scroll page and confirm background blobs shift subtly.
- Verify drift animation remains calm and not distracting.

## Diagram + Animation
- Confirm pathway nodes appear as floating cards.
- Hover nodes and verify subtle scale + glow.
- Move controls and confirm edge pulse animation updates.

## Organ Popups
- Click pancreas/liver/muscle/adipose/kidney/heart/eye/nerves buttons.
- Confirm side drawer opens with original SVG mini-diagram and short explanation.
- Confirm metric chips render in drawer.

## Charts
- Confirm glucose and insulin curves render smoothly.
- Hover chart and verify tooltip appears with timepoint values.
- Confirm baseline + peak markers are visible.

## Micro-Challenges
- Run each section challenge button.
- Verify feedback message appears and completion updates progress indicator.

## Accessibility
- Tab through buttons/controls and verify visible focus rings.
- Confirm controls are keyboard operable.
- Check reduced-motion mode (if enabled) disables animations.

## Reliability
- Verify no console errors during navigation and interactions.
- Verify layout remains stable across desktop and mobile widths.
